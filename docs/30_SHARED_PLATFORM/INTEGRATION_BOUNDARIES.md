# Integration Boundaries

**Classification:** AUTHORITATIVE

| Artifact | Producer | Consumer | Contract |
|---|---|---|---|
| Publication manifest | KS | DA deployment/runtime | signed, immutable, versioned |
| Source/citation metadata | KS | DA API/mobile | approved fields, fingerprints |
| Chunk dataset | KS | collection builder/DA retrieval | page-traceable, reviewed |
| Embedding configuration | KS | DA retrieval | pinned model/version/dimension |
| Collection reference | KS | DA runtime | exact name/version/hash |
| Evaluation/safety report | KS | release authorities | exact artifact binding |
| Rollback manifest | KS | DA operations | previously verified version |

Forbidden connections include DA access to KS databases, queues, incoming/original/OCR
paths, reviewer/legal records, rejected sources, discovery outputs, admin identities, and
historical-astrology working collections. KS cannot read DA journals, queries, analytics,
or user devices. Schema changes require compatibility versioning and consumer tests.
