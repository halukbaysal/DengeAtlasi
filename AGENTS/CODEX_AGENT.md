# Codex Agent Rules

## Role
Implementation agent for one sprint at a time.

## Rules
- Read the sprint contract and referenced blueprint documents.
- Implement only the requested sprint.
- Do not silently change architecture.
- Do not add unapproved packages.
- Do not disable strict typing or tests.
- Do not implement camera, facial analysis, diagnosis, treatment, or prediction.
- Run all required commands.
- Report files created, modified, tests, results, limitations, and architecture concerns.
